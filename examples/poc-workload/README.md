This workload exercises all **7 Pillars of Observability**:
1. **Pillar 1 (Metrics)**: Micrometer Prometheus actuator endpoint (`/actuator/prometheus`) exposing JVM memory, GC, and container stats.
2. **Pillar 2 (Logs)**: Structured logging with Mapped Diagnostic Context (MDC) for trace correlation.
3. **Pillar 3 (Distributed Tracing)**: W3C `traceparent` injection into Kafka headers (`KafkaTraceProducer.java`) and extraction (`InventoryEventConsumer.java`), with SQL Server traced spans (`OrderService.java`).
4. **Pillar 4 (Continuous Profiling)**: Custom Java Flight Recorder events (`jdk.jfr.Event`) emitted during order processing.
5. **Pillar 5 (RUM)**: Integrates with frontend tracing headers passed from browser clients.
6. **Pillar 6 (Network eBPF)**: Standard container TCP sockets monitored by kernel probes.
7. **Pillar 7 (Security & AIOps)**: Secure runtime privileges and predictable error propagation for causal root-cause analysis.
